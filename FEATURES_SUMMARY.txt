================================================================================
  API ENDPOINTS (Web Dashboard)
================================================================================

  GET    /                          Dashboard UI
  GET    /api/status               Current system status
  GET    /api/metrics              Performance metrics
  GET    /api/presets              List all presets
  GET    /api/presets/<name>       Get preset details
  POST   /api/presets/<name>/load  Load a preset
  POST   /api/presets              Create new preset
  DELETE /api/presets/<name>       Delete preset
  POST   /api/mode                 Change operating mode
  POST   /api/calibrate            Start calibration
  POST   /api/gesture              Trigger gesture action

================================================================================
  KEYBOARD SHORTCUTS (During Execution)
================================================================================

  Q              Quit application
  C              Run calibration wizard
  R              Toggle gesture recording
  P              Play last recorded gesture
  M              Cycle multi-hand modes
  1-6            Load preset (1-6)
