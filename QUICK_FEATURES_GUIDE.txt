 FEATURE CHEAT SHEET
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  PRESET MANAGEMENT
   What: Save/load control configurations instantly
   Start: python -m utils.preset_manager
   Code:  pm = PresetManager()
          pm.create_preset("my_synth", config_dict)
          pm.load_preset("my_synth")
   Built-in: filter_cutoff, reverb_mix, volume, dual_hand_xy, pad_performance, fast_synth

2️⃣  GESTURE RECORDING
   What: Record hand motions and replay as MIDI
   Key:  Press 'R' to start/stop
   Code:  recorder.start_recording("sweep")
          # Move hand...
          recorder.stop_recording()
   Replay: recorder.load_recording("sweep")
           player.start_playback(loop=True)

3️⃣  PERFORMANCE METRICS
   What: Monitor FPS, latency, detection rate
   View: Web dashboard at http://localhost:5000
   Code:  monitor.record_frame(metrics)
          summary = monitor.get_performance_summary()
   Metrics: FPS, Latency, Frame Time, Detection %, MIDI Rate

4️⃣  CALIBRATION WIZARD
   What: Interactive 5-step setup for your environment
   Start: Press 'C' during execution OR use web dashboard
   Steps: Lighting → Position → Distance → Size → Confidence
   Time: ~2 minutes

5️⃣  GESTURE RECOGNITION
   What: Detect swipes, circles, shakes - trigger actions
   Setup: recognizer.register_callback(GestureType.SWIPE_LEFT, my_function)
   Gestures: SWIPE_LEFT, SWIPE_RIGHT, SWIPE_UP, SWIPE_DOWN, 
             CIRCLE_CW, CIRCLE_CCW, SHAKE

6️⃣  WEB DASHBOARD
   What: Browser-based real-time monitoring & control
   URL:   http://localhost:5000
   Start: python main.py --web-dashboard
   Shows: Status, Metrics, Presets, Calibration, Mode Control

7️⃣  MULTI-HAND MODES
   What: Control multiple MIDI parameters with multiple hands
   Modes: 
     • DUAL_HAND_XY: Left hand→X, Right hand→Y
     • INDEPENDENT_CC: Each hand→separate CC
     • MULTI_INSTRUMENT: Each hand→different MIDI channel
     • SYNCHRONIZED: All hands→averaged control
   Switch: Code or web dashboard

EXAMPLE 1: Record a Gesture
────────────────────────────
from utils.gesture_recorder import GestureRecorder

recorder = GestureRecorder()
recorder.start_recording("my_sweep")
# Move hand in front of camera
for _ in range(100):
    recorder.record_frame(x, y, distance, confidence=0.95)
recorder.stop_recording()


EXAMPLE 2: Load and Use a Preset
──────────────────────────────────
from utils.preset_manager import PresetManager

pm = PresetManager()
config = pm.load_preset("filter_cutoff")
# Now use config to setup your controller


EXAMPLE 3: Monitor Performance
───────────────────────────────
from utils.performance_metrics import PerformanceMonitor, FrameMetrics

monitor = PerformanceMonitor()
# In main loop:
metrics = FrameMetrics(...fps, detection_time, etc...)
monitor.record_frame(metrics)

# Check health
health = monitor.get_health_status()
print(f"System: {health['status']}")


EXAMPLE 4: Detect Gestures
───────────────────────────
from utils.gesture_recognition import GestureRecognizer, GestureType

recognizer = GestureRecognizer()

def on_swipe_left():
    print("You swiped left!")

recognizer.register_callback(GestureType.SWIPE_LEFT, on_swipe_left)

# In main loop:
recognizer.add_point(hand_x, hand_y, time.time())


EXAMPLE 5: Multi-Hand Dual XY
──────────────────────────────
from hand_tracker.multi_hand_controller import MultiHandController, MultiHandMode

controller = MultiHandController(midi_controller)
controller.set_mode(MultiHandMode.DUAL_HAND_XY)

# In main loop:
detected_hands = hand_detector.detect(frame)
midi_messages = controller.update_hands(detected_hands)
# Left hand X → CC 1, Right hand Y → CC 11

 COMMON ISSUES & FIXES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Hand not detected
   ✅ Run calibration wizard: Press 'C'
   ✅ Check lighting (should be 50-200 brightness)
   ✅ Increase detection confidence threshold (config)

❌ Low FPS (<20)
   ✅ Disable web dashboard
   ✅ Reduce gesture history size
   ✅ Check CPU usage (should be <35%)

❌ Latency too high (>100ms)
   ✅ Check "Bottleneck" in web dashboard metrics
   ✅ Reduce detection resolution
   ✅ Disable gesture recording

❌ MIDI messages not reaching DAW
   ✅ Check MIDI output port in config
   ✅ Verify DAW MIDI input is enabled
   ✅ Test with DAW's MIDI monitor

❌ Web dashboard not accessible
   ✅ Check if port 5000 is available (netstat -an | grep 5000)
   ✅ Try different port: --web-port 8000
   ✅ Check firewall settings
