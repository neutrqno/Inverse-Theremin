  sqrt           Square root mapping

  To change: config/default_config.json → mapping.curve

  Device not connecting:
    → Check IP is correct: ping 192.168.29.156
    → Verify Wi-Fi is connected to: jio_ub12
    → Restart device: unplug 30 seconds, plug back

  Proximity values not updating:
    → Check Home Assistant entity exists
    → Verify Home Assistant token is valid
    → Check proximity sensor works in Home Assistant UI

  MIDI not working:
    → Verify MIDI device in DAW is enabled
    → List MIDI devices: python -c "import mido; print(mido.get_output_names())"
    → Check CC number is supported by synth
    → Test: python examples/basic_usage.py basic

  Values too noisy:
    → Increase smoothing: config/default_config.json → processing.smoothing.factor
    → Increase polling interval: processing → poll_interval_ms (higher = more stable)
    → Enable deadzone: processing → deadzone.enabled
